# Физические кнопки через эмуляцию облака Bose (AfterTouch)

Дата: 2026-09-19. Статус: дизайн утверждён пользователем, спецификация на проверке.

## Проблема

Шаг 1 плана (разведка на SoundTouch 10, `10.109.159.11`, прошивка 27.0.6) показал:

| Способ нажатия | Результат |
|---|---|
| Физическая кнопка 1–6 | оранжевое мигание, в WebSocket событий нет (`nowSelectionUpdated` и `userActivityUpdate` не приходят) |
| `POST /key PRESET_1` (REST) | приходит `nowSelectionUpdated` с пресетом |
| UPnP `SetAVTransportURI` + `Play`, поток через ПК по HTTP | играет |
| UPnP с потоком напрямую из интернета | `PAUSED_PLAYBACK`, тишина |
| `POST /storePreset`, `source="UPNP"` | принимается, виден в `/presets` |

Вывод: схема «мост слушает кнопки по WebSocket» для физических кнопок SoundTouch 10 не работает. Прошивка обрабатывает нажатие внутри и обращается к облаку Bose (`margeURL=https://streaming.bose.com`), которого больше нет.

## Решение

Вместо собственной эмуляции ставим готовый сервер-замену облака [AfterTouch](https://gesellix.github.io/Bose-SoundTouch/) и перенаправляем на него **обе колонки**: SoundTouch 10 и SoundTouch 20. Физические кнопки, по заявлению проекта, работают полностью, включая сохранение удержанием.

Собственный мост (`src/`) на этом этапе не участвует и остаётся в репозитории. Его судьба (удалить, оставить как запасной вариант или использовать поиск Radio-Browser) решается после проверки.

## Порядок действий

Каждый шаг, меняющий состояние, выполняется только после подтверждения пользователя.

1. **Установка AfterTouch** на ПК (бинарник для Windows). Порт по умолчанию 8000; при конфликте с нашим мостом один из двух переносится. Добавить обе колонки по IP.
2. **Sync** каждой колонки: AfterTouch забирает её состояние и сохраняет вне колонки копии `SoundTouchSdkPrivateCfg.xml` и `/etc/hosts`. Колонка не меняется.
3. **Pre-flight-проверки** мастера миграции (доступ на запись, HTTPS с колонки).
4. **Включение SSH и перенаправление**, по одной колонке за раз, начиная с SoundTouch 10:
   - SSH включается через telnet:17000 (`soundtouch-cli setup enable-ssh`); порт 17000 на SoundTouch 10 открыт, порт 22 закрыт. USB-флешка с файлом `remote_services` остаётся запасным способом.
   - Правка адресов серверов в `/opt/Bose/etc/SoundTouchSdkPrivateCfg.xml` (мастером AfterTouch), создаются файлы `.original`.
5. **Проверка на каждой колонке:** станция назначена на кнопку 1, физическая кнопка включает её. Затем кнопки 2–6, перезагрузка колонки, перезапуск сервера.

## Обе колонки

- SoundTouch 20: IP пока неизвестен; нужен до шага 1. Разведку по её кнопкам (`scripts/probe.js`) стоит сделать до миграции: возможно, у неё физические кнопки события присылают, и это станет запасным вариантом.
- Наборы станций: раньше требовалось, чтобы у каждой колонки был свой набор из 6 станций. Нужно проверить, хранит ли AfterTouch пресеты для каждой колонки отдельно (в структуре данных есть каталог `data/default/devices/<SERIAL>/`) или общий набор на аккаунт.
- Миграция делается по одной колонке: сначала SoundTouch 10, после успеха SoundTouch 20.

## Откат

- «Revert to Defaults» в интерфейсе AfterTouch восстанавливает файлы `.original`.
- Если интерфейс недоступен: восстановить файлы вручную по SSH из копий в `data/default/devices/<SERIAL>/` (`scp`).
- Крайний случай: заводской сброс колонки кнопочной комбинацией. Прошивка сохраняется.

## Риски

- Правка системного конфига колонки; теоретический риск «кирпича» смягчается резервными копиями и pre-flight-проверками.
- Мост и облако должны работать постоянно: без сервера AfterTouch кнопки снова не работают.
- Планшет на Android (Termux): у AfterTouch в документации нет Android; для ПК и Raspberry Pi есть. Хост может измениться (ПК или Raspberry Pi вместо планшета).

## Открытые вопросы (проверить по ходу)

1. Как задать в AfterTouch произвольный URL интернет-радио (не TuneIn) для кнопки.
2. Играют ли HTTPS-потоки через его прокси (колонка сама HTTPS-потоки не тянет).
3. Раздельные наборы станций для двух колонок.
4. Не блокирует ли что-либо на этом ПК (межсетевой экран Windows) входящие соединения колонок на порт сервера.
