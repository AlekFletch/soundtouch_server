# Что сделать дома (шаг 1)

Нужен компьютер в той же сети, что и колонка, с Node.js 22+ и git.

1. Забрать проект:
   ```bash
   git clone https://github.com/AlekFletch/soundtouch_server.git soundtouch-bridge
   ```
   ```bash
   cd soundtouch-bridge
   ```
2. Убедиться, что колонка в Wi-Fi (на дисплее горит значок Wi-Fi), и узнать её IP в списке устройств роутера.
   Если колонка не в сети — подключить её через приложение SoundTouch (локальная настройка работает и без облака).
3. На время проверки выключить VPN на компьютере.
4. Запустить разведку (подставить IP):
   ```bash
   node scripts/probe.js 192.168.1.50
   ```
   Когда появится строка «WebSocket … нажимайте кнопки», по очереди:
   - коротко нажать кнопки 1…6 на колонке (между нажатиями 3–5 секунд);
   - то же самое с пульта, если он есть;
   - записать, что показывал дисплей.

   Затем Ctrl+C. Лог окажется в `data/probe-*.log`.
5. Тест воспроизведения:
   ```bash
   node scripts/play-test.js 192.168.1.50
   ```
   Колонка должна заиграть тестовое радио.
6. Запустить мост и попробовать форму:
   ```bash
   npm start
   ```
   Открыть `http://localhost:8000`, указать IP колонки, настроить кнопку 1 и нажать её на колонке.
   Если появится предупреждение «не записана на колонку» — это нормально для первого прогона.
7. Открыть сессию Claude Code в папке проекта и передать лог из `data/probe-*.log`, вывод шагов 5–6 и что показывал дисплей.
