# Что сделать дома (шаг 1)

Нужен компьютер в той же сети, что и колонки (SoundTouch 20 и SoundTouch 10), с Node.js 22+ и git.

1. Забрать проект:
   ```bash
   git clone https://github.com/AlekFletch/soundtouch_server.git soundtouch-bridge
   ```
   ```bash
   cd soundtouch-bridge
   ```
2. Убедиться, что обе колонки в Wi-Fi (значок Wi-Fi на дисплее SoundTouch 20, индикатор Wi-Fi на SoundTouch 10 горит белым), и узнать их IP в списке устройств роутера.
   Если колонка не в сети — подключить её через приложение SoundTouch (локальная настройка работает и без облака).
3. На время проверки выключить VPN на компьютере.
4. Разведка — **для каждой колонки отдельно** (подставить её IP):
   ```bash
   node scripts/probe.js 192.168.1.50
   ```
   Когда появится строка «WebSocket … нажимайте кнопки», по очереди:
   - коротко нажать кнопки 1…6 на колонке (между нажатиями 3–5 секунд);
   - то же самое с пульта, если он есть;
   - записать, что показывал дисплей или индикаторы.

   Затем Ctrl+C. Лог окажется в `data/probe-*.log`. Повторить для второй колонки.
5. Тест воспроизведения на каждой колонке:
   ```bash
   node scripts/play-test.js 192.168.1.50
   ```
   Колонка должна заиграть тестовое радио.
6. Запустить мост и попробовать форму:
   ```bash
   npm start
   ```
   Открыть `http://localhost:8000`, нажать «＋ Добавить колонку» → «Найти в сети» (или ввести IP) и добавить обе колонки.
   Настроить кнопку 1 на каждой и нажать её на колонке. Проверить «Скопировать станции».
   Если появится предупреждение «не записана на колонку» — это нормально для первого прогона.
7. Открыть сессию Claude Code в папке проекта и передать логи `data/probe-*.log` (по одному на колонку), вывод шагов 5–6 и что показывали колонки.
