
Не найден Git Bash — без него скрипт перенастройки не запустится.

Что сделать:
  1. Установите Git for Windows: https://git-scm.com/download/win
     (при установке все настройки можно оставить по умолчанию).
  2. Снова дважды щёлкните «Починить AfterTouch.bat».

Если Git стоит в необычной папке, откройте Git Bash в папке проекта
и выполните вручную:
    bash scripts/fix-aftertouch.sh
